# Building the AkisLink snapshot

Android source includes the modified native ByeDPI engine; no native submodule checkout is needed. Use JDK 21, Android SDK 34 / build-tools 34.0.0, NDK 26.1.10909125 and CMake 3.22.1. Set JAVA_HOME, ANDROID_HOME and optionally GRADLE_USER_HOME, then run android/gradlew.bat -p android assembleDebug lintDebug. A release build needs SPLITWIRE_SIGNING_STORE and SPLITWIRE_SIGNING_PASSWORD environment variables for a PKCS12 key with alias splitwire; use your own key for independent redistribution. Original signing credentials are deliberately excluded. Run assembleRelease lintRelease. PowerShell packaging/Build-AndroidRelease.ps1 automates local signing/builds but its JDK/SDK locations must be adapted on another PC.

On a Windows system using a non-ASCII workspace path, run JVM tests separately with -Dorg.gradle.jvmargs="-Xmx2048m -Dfile.encoding=windows-1254" (adapt to the native Windows code page). Keep ordinary native compilation in UTF-8; mixing the two passes corrupts native CMake path metadata.

Windows: place the official sing-box 1.14.2 Windows x64 binary in windows/bin/sing-box.exe and its distribution LICENSE in windows/bin/sing-box-1.14.2-windows-amd64/LICENSE. The accompanying sing-box source archive is revision af6e64c3b69e6132ebaee0e1a3d24e93903f6709. Consult its source/build instructions to build that dependency yourself. Use Windows .NET Framework 4.8 compiler and Windows PowerShell 5.1 to run packaging/Build-WindowsRelease.ps1. It embeds the scripts, logo, engine, notices and a hash manifest into a standalone launcher. No hidden/generated .NET project is required.

Desktop UI regression: powershell.exe -NoProfile -ExecutionPolicy Bypass -STA -File windows/SplitWire.ps1 -SmokeTest. This uses isolated smoke settings, exercises real language buttons and checks state labels without starting/stopping routing. Test the packaged EXE with --smoke-test --report <absolute-json-path>; this verifies extraction and GUI as shipped. Network and phone installation tests are separate.

Snapshot: after both binaries and corresponding vendor source are present, packaging/Save-ReleaseSnapshot.ps1 copies docs, creates Source.zip excluding build caches/runtime/private keys, then records hashes and a bundle. It refuses to overwrite Source.zip. Increment the version in Gradle, launcher and packaging scripts before saving a later release. Keep a protected backup of the private release key/password pair outside the source folder; an existing installation cannot be upgraded with another key.
